# Транспортное приложение

`transport-case/` содержит PNG-экспорты мокапов из макетов кейса единого
транспортного приложения Figma `2082:6266` и `2348:4584`. Экспорты получены
через Figma MCP и используются в `site/transport-app.html`.

`transport-case/mobile/` — отдельные мобильные источники из обновлённого
`2348:4584`. PNG сохраняют окружение соответствующей карточки, поэтому
не создают дополнительной прямоугольной подложки. Телефоны `expiring`,
`last-trip`, `expired` и `transfer-ticket` собраны в SVG из исходных PNG-слоёв
Figma (экран, корпус, камера) и геометрии островка: обычный экспорт этих
узлов обрезается границами родительского фрейма. SVG содержат изображения
внутри файла и не требуют внешних URL.
